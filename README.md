# Roast & Bloom — Coffee Shop Website

A responsive fictional coffee shop landing page built with HTML and CSS for a web development portfolio.

## Features
- Responsive layout for mobile and desktop
- Menu, story, and visit sections
- CSS illustration in place of external stock imagery
- Basic SEO title, meta description, and semantic HTML

## Live demo
After enabling GitHub Pages in **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then save. The expected URL is `https://dimasalha.github.io/coffee-shop-website/` once GitHub Pages finishes deploying.

This is a fictional portfolio demo, not a real café.
